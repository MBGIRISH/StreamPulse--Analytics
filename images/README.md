# Images Directory

This directory contains visualization images and screenshots for the project README.

## Recommended Images to Include

1. **Dashboard Screenshots**: Screenshots of the Streamlit dashboard showing key visualizations
2. **Model Performance Charts**: Confusion matrices, ROC curves, and model comparison charts
3. **EDA Visualizations**: Key exploratory data analysis charts (heatmaps, genre trends, user segments)
4. **Architecture Diagrams**: System architecture or pipeline flow diagrams (optional)
5. **Recommendation Examples**: Sample recommendation outputs displayed in the dashboard

## Usage

To add images to the main README:

1. Save your image files in this directory (PNG, JPG, or SVG format recommended)
2. Reference them in `README.md` using:
   ```markdown
   ![Image Description](images/filename.png)
   ```

## File Naming Convention

Use descriptive, lowercase filenames with hyphens:
- `dashboard-overview.png`
- `churn-roc-curves.png`
- `user-segments-clustering.png`
- `genre-trends-heatmap.png`
